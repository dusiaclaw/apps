# My Apps

A carousel launcher for my web apps hosted on GitHub Pages. Swipe between the apps; each card shows a screenshot, a short description, an **Open** button and a link to the source.

**Open it:** https://dusiaclaw.github.io/apps/ (GitHub Pages must be enabled for this repository: Settings → Pages → deploy from `main`, root folder). In Chrome on Android, use "Add to Home screen" to install it.

## Apps

- [Receipt Archive](https://dusiaclaw.github.io/ReceiptArchive/): receipts to a PDF expense report
- [Audio Shelf](https://dusiaclaw.github.io/AudioShelf/): audiobook library
- [Ice Bath Log](https://dusiaclaw.github.io/ice-bath-log/): cold-water dip tracker
- [Sick Log](https://dusiaclaw.github.io/SickLog/): sick-day diary
- [Hexfarers](https://dusiaclaw.github.io/hexfarers/): hex-island trading game
- [Tactical Baseball](https://dusiaclaw.github.io/tactical-baseball/): dice-and-cards baseball game

## Adding an app

Everything is in `index.html`. Add an entry to the `APPS` list with the repo name, description, a 540×1110 screenshot and an icon (embedded as data URLs). Screenshots use sample data only.
